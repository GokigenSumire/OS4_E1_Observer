本模块是可选兼容组件，不是主壁纸的安装前提。主壁纸可独立运行；原生手势正常的设备无需 Root、LSPosed 或本模块。当前独立包 `personal.wallpaper.os4.e1`，仅匹配正式主壁纸 `personal.wallpaper.os3`；两者采用各自独立正式证书，不覆盖旧 `.debug` 沙箱。正式首页只显示日常持久开关、当前实际状态、故障恢复提示与主壁纸入口，不再含测试工具界面；新候选设备功能尚为 `NOT_RUN`，不把旧版本实测迁移至此。

新装默认关闭。开关保存于模块自己的设备保护私有沙箱；用户打开后持续运行，没有12小时到期限制，重启后自动按已保存的开启意愿恢复。用户关闭则保存关闭意愿并执行当前安全恢复。关闭保存失败时必须明确提示，不能假称下次重启不会再开。当前实际是否生效仍以系统回执为准，保存开启不代表hook已加载或所有故障已恢复。

需要兼容的设备须已有 Root 与 LSPosed，用户自行安装模块。HOME兼容需要「系统框架／Android」，LOCK兼容还需要「系统界面／SystemUI」，由用户安排正常重启加载；AI不安装工具或操作手机。若已有旧调试模块，由用户在 LSPosed 禁用旧模块并正常重启，不能与新模块双激活。新装不会自行启用；只有用户先保存开启，才允许正常开机广播恢复。打开主应用、查询状态和刷新不会开启模块。关闭模块不等于运行中hook已解除。

仅项目壁纸实际选中／可见时，在唯一认证HOME同一自然populate的false getter临时返回true，不写attrs、系统文件或输入mask，无native hook；system_server不读写持久开关文件。精确滑动60秒最多2000次覆盖，超限或异常先撤许可；恢复最多20秒，未确认锁定且卸钩，不能把关闭按钮当native已立即恢复。开机恢复先核精确模块版本、boot／epoch及永久策略，恢复未确认／受限时不无限重试，不绕过安全锁。正式界面只保留日常开关、实际状态和应用入口，不提供测试、短诊断、标记或导出工具；AI构建与自动测试证据保留在电脑端。
